# 🏛️ HeritageVoice AI

## Multilingual Smart Tour Guide

HeritageVoice AI is an AI-powered multilingual smart tour guide that helps users explore historical monuments through image recognition, factual historical information, multilingual narration, and interactive voice/text conversations.

Developed for the **OMNIKON National Hackathon 2026** by **Team Tech Sparker**.

---

## 📌 About the Project

HeritageVoice AI transforms the traditional tourist guide experience into an interactive AI-powered experience.

A user can simply capture or upload a picture of a monument. The application uses **Google Gemini Vision** to identify the monument and provides its historical and cultural information.

Users can then listen to the monument's story in their preferred language and ask follow-up questions using text or voice.

---

## ✨ Features

### 📷 1. Monument Recognition

Users can capture a monument using their camera or upload an image.

Google Gemini Vision analyzes the image and identifies the monument.

### 📚 2. Factual Historical Information

The application uses a structured monument catalog to provide reliable historical information and reduce unsupported AI-generated facts.

### 🌍 3. Multilingual Support

Users can explore monument information in multiple languages, including:

- English
- Hindi
- Gujarati
- Marathi
- Tamil
- Telugu
- Bengali
- Kannada
- French
- Spanish

### 🔊 4. Voice Narration

Monument stories can be converted into spoken narration, allowing users to listen while exploring a heritage site.

### 💬 5. Interactive Q&A

Users can ask questions about the identified monument.

For example:

- Who built this monument?
- When was it constructed?
- Why is it historically important?
- What architectural style does it use?

### 🎙️ 6. Voice Interaction

Users can ask questions using their microphone through browser-supported speech recognition.

### 🔄 7. Language Switching

Users can change the language after identifying a monument and receive the monument information and narration in the newly selected language.
